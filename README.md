A basic Jupyter Notebook Python Auto Marking.

See [sample.ipynb](sample.ipynb) for format of notebook.

Your notebook must have a markdown cell.

This cell must have the header 
```
# Problem statment
```

The header
```
## Sample input
```
is used to specified the inputs to the programme. Each input is separated by a new line.

The header
```
## Sample output
```
is used to specified the outputs of the programme to standard out if execution.

You can have more than one pair of input/output.

If you have more than a mardown cell that contains 
```
# Problem statment
```
the last cell will be used.
